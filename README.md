# 👨‍💻 Mihir Verma | Personal Portfolio

> An interactive developer portfolio showcasing my work as a Python Backend Developer and AI/ML Engineer. 

Built on a modern React and Vite stack, this space highlights my experience in crafting robust REST APIs, deploying deep learning models, and analyzing complex datasets. 

🔗 **[View Live Website](https://mihir-protfolio-website.vercel.app/)**

---

## ⚡️ Tech Stack

This project recently transitioned from a vanilla HTML/JS structure to a modern, highly optimized component-based architecture.

* **Frontend Framework:** React.js
* **Build Tool:** Vite (for lightning-fast HMR and optimized production builds)
* **Styling:** Tailwind CSS
* **Deployment:** Vercel
* **Future Integration:** FastAPI (Python) for handling dynamic backend operations and ML model serving.

---

## ✨ Key Features

* **Optimized Performance:** Implemented React `lazy()` and `<Suspense>` for code-splitting, ensuring lightning-fast initial load times.
* **Modern Asset Delivery:** Preloaded Largest Contentful Paint (LCP) elements and utilizes WebP/WebM formats to prevent React waterfall delays.
* **Responsive UI:** Fully mobile-responsive design utilizing Tailwind's utility classes.
* **Live AI Demos:** Direct integrations and links to hosted AI/ML projects (e.g., Zomato Review Sentiment Analysis).
* **Contact Integration:** Functional contact form powered by Web3Forms.

# Mihir Portfolio — Brand Guidelines

**Brand Positioning:**
AI/ML Engineer & Python Backend Developer

**Brand Personality:**
Technical • Intelligent • Minimal • Confident • Modern • Reliable

**Primary Goal:**
Make recruiters understand **who Mihir is, what he builds, and what technologies he can work with within 10–15 seconds.**

---

## 1. Brand Identity

### Brand Statement

> **Building intelligent systems that turn data into useful products.**

### Professional Positioning

**AI/ML Engineer | Python Backend Developer**

Supporting expertise:

* Machine Learning
* Deep Learning
* Computer Vision
* NLP
* Data Analytics
* REST APIs
* Backend Development
* IoT + AI

### Brand Keywords

`AI` `Engineering` `Intelligence` `Python` `Backend` `Innovation` `Data` `Systems`

Avoid positioning the site as:

* A generic coding portfolio
* A purely frontend developer portfolio
* An “AI enthusiast” website without evidence
* An overly flashy developer landing page

---

# 2. Visual Direction

### Design Concept

**“Intelligent Technology — Minimal Interface”**

The visual language should communicate:

**Human → Data → Intelligence → System → Impact**

Use technical visual elements subtly:

* Neural-network patterns
* Data grids
* Code-inspired details
* System diagrams
* Small technical labels
* Subtle gradients
* Structured cards

Avoid excessive:

* Glowing effects
* Neon colors
* 3D objects
* Particle animations
* Excessive glassmorphism
* Decorative AI imagery

The website should look like an **engineer's professional product**, not an AI-generated template.

# 3. Color System

### Primary Palette

| Token            | Color     | Usage                     |
| ---------------- | --------- | ------------------------- |
| `Background`     | `#0A0A0A` | Main background           |
| `Surface`        | `#111111` | Cards / sections          |
| `Surface 2`      | `#181818` | Hover / elevated surfaces |
| `Primary`        | `#E50914` | Brand accent / CTA        |
| `Primary Hover`  | `#F5222D` | Hover state               |
| `Text Primary`   | `#F5F5F5` | Headings                  |
| `Text Secondary` | `#A3A3A3` | Body text                 |
| `Text Muted`     | `#737373` | Metadata                  |
| `Border`         | `#262626` | Dividers / cards          |

### Accent Color

**Netflix-inspired Red — `#E50914`**

Use red strategically for:

* CTA buttons
* Active navigation
* Important keywords
* Links
* Selected technologies
* Small visual highlights

**Do not use red for large amounts of body text.**

The red should represent **action and intelligence**, not become the entire visual identity.

# 7. Hero Section

The hero is the most important recruiter-facing section.

### Recommended Structure

```text
AI/ML ENGINEER
PYTHON BACKEND DEVELOPER

Building intelligent systems
with Python, Machine Learning
and modern backend technologies.

[ View Projects ] [ Resume ]

GitHub     LinkedIn     Email
```

Add a small technical status line:

```text
● OPEN TO AI/ML & BACKEND OPPORTUNITIES
```

### Hero Principle

Do not make recruiters read a paragraph.

The first screen should answer:

1. Who are you?
2. What do you do?
3. What technologies do you use?
4. What should the recruiter click?

# 11. Project Visual Hierarchy

Each project should communicate:

```text
PROBLEM
↓
SOLUTION
↓
TECHNOLOGY
↓
RESULT
```

Example:

**Asthma Risk Prediction**

> Developed a Random Forest-based ML system to predict asthma risk using patient health and lifestyle features.

**Technology**

`Python` `Scikit-learn` `Random Forest` `Flask`

**Result**

> Integrated the trained model into an interactive Flask dashboard.

This is much stronger for recruiters than simply saying:

> “Made an asthma prediction project.”

### Primary CTA

```text

```

### Secondary CTA

```text
DOWNLOAD RESUME
```

### Tertiary

```text
VIEW GITHUB ↗
```

### Button Rules

Primary button:

* Red background
* White text
* 8–10px radius

Secondary:

* Transparent
* Border
* White/light text

Hover:

* Slight brightness increase
* Small translation or scale
* 150–250ms transition

Avoid excessive button animations.

---

# 13. Cards

### Style

```text
Background: #111111
Border: #262626
Radius: 12–16px
Padding: 24–32px
```

On hover:

```text
Border → Accent
Transform → translateY(-4px)
Shadow → subtle
```

Keep cards visually consistent.

Do not give every card a different color.

---

# 14. Motion Guidelines

Motion should communicate **interaction**, not decoration.

### Recommended

* Fade-in sections
* Slight upward reveal
* Card hover
* Button transitions
* Smooth navigation
* Project image transitions

### Timing

```text
Micro interaction: 150–200ms
Component: 200–300ms
Page/section: 400–600ms
```

Avoid:

* Constant floating animations
* Excessive parallax
* Long loading animations
* Flashing effects
* Continuous background movement

# 17. Accessibility

Target **WCAG 2.2 AA-level practices** wherever practical.

Minimum requirements:

* Strong text/background contrast
* Keyboard navigation
* Visible focus states
* Semantic HTML
* Descriptive link text
* Alt text for meaningful images
* Do not communicate information through color alone
* Respect reduced-motion preferences

WCAG's established minimum contrast requirement is **4.5:1 for normal text and 3:1 for large text**.

# 18. Content Voice

### Tone

**Confident + Technical + Clear**

Write:

> Built a Random Forest-based asthma risk prediction system using Python and Scikit-learn.

Instead of:

> I am extremely passionate about creating innovative AI solutions.

Write:

> Developed a meeting summarization pipeline using Whisper, speaker diarization, NLP, and automated PDF generation.

### Voice Rules

Use:

* Built
* Developed
* Implemented
* Designed
* Integrated
* Automated
* Optimized
* Deployed

Avoid excessive:

* Passionate
* Amazing
* Revolutionary
* Cutting-edge
* World-class
* Next-generation

Let the projects demonstrate those qualities.

# 21. Brand Do's

### DO

* Keep the design minimal
* Prioritize projects
* Use real technical evidence
* Show GitHub links
* Use consistent spacing
* Maintain strong contrast
* Keep animations subtle
* Make the site fast
* Optimize mobile experience
* Use professional language

### DON'T

* Overuse red
* Use 10+ colors
* Add unnecessary animations
* Use skill percentage bars
* Fill the site with generic quotes
* Use huge paragraphs
* Hide your GitHub/LinkedIn
* Put every technology on the homepage
* Use excessive glassmorphism
* Make recruiters hunt for your resume

# 23. Brand Summary

**Mihir Portfolio should feel like:**

> **A professional AI engineer's digital workspace — technical, minimal, intelligent, and focused on real projects.**

### Visual Formula

```text
Dark Foundation
        +
Controlled Red Accent
        +
Clean Typography
        +
Technical Details
        +
Strong Project Evidence
        +
Subtle Motion
        =
Mihir AI/ML Engineer Brand
```

The key principle is **“less decoration, more evidence.”**

Your portfolio should not try to impress recruiters by looking complicated. It should impress them by making your **AI/ML + backend engineering capability immediately obvious**.

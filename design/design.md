# Mihir Portfolio — Brand Guidelines

## Positioning
AI/ML Engineer + Python Backend Developer.

The portfolio should feel technical, modern, premium,
credible, and recruiter-focused.

## Visual Direction
- Dark-first interface
- Minimal technical aesthetic
- Strong typography
- Generous whitespace
- Restrained accent usage
- Subtle animations
- No generic AI/cyberpunk aesthetics

## Colors

Background: #08090A
Surface: #111315
Elevated Surface: #181B1F
Border: #272B30

Primary text: #F5F7FA
Secondary text: #A7ADB5
Muted text: #737A84

Accent: #E50914
Accent hover: #FF1A25

Use red as an accent, not as the dominant color.

## Typography

Primary: Inter
Technical/code: JetBrains Mono

Hero: 64–80px desktop
H1: 48–56px
H2: 36–42px
H3: 24–28px
Body: 16–18px

Use responsive typography with clamp().

## Layout

Maximum width: 1200–1280px.

Spacing follows an 8px system:
8, 16, 24, 32, 48, 64, 80, 96, 128px.

Mobile horizontal padding: 20–24px.
Desktop horizontal padding: 48–64px.

## Components

Use reusable components.

Buttons:
- Primary: red accent
- Secondary: surface + border
- Ghost: transparent

Cards:
- Surface background
- Subtle border
- 12–16px radius
- Minimal hover movement

Icons:
Use Lucide consistently.

## Motion

Use subtle motion only.

Typical duration: 150–300ms.

Support prefers-reduced-motion.

Avoid:
- excessive parallax
- constant animations
- glowing effects
- unnecessary transitions

## Recruiter UX

Within 30 seconds, visitors should understand:

1. Who Mihir is
2. AI/ML specialization
3. Technical stack
4. Strongest projects
5. How to contact him

Resume, GitHub and LinkedIn should be easy to find.

## Accessibility

Target WCAG 2.2 AA.

Maintain:
- keyboard navigation
- visible focus states
- semantic HTML
- sufficient contrast
- meaningful alt text
- responsive layouts

## Don't

Avoid:
- excessive gradients
- neon/cyberpunk styling
- generic AI imagery
- giant skill-logo walls
- excessive animations
- unnecessary decorative elements
- inconsistent components
